A few good questions.

What can I use today?

The Congress and Los Angeles law search projects are public. The Alcove core is available to run yourself. Home is a private prototype with a recorded demonstration; Business examples illustrate workflows still in development.

Does Home already connect to all my accounts?

No. The demonstration uses selected records from a real personal archive. It does not demonstrate a complete account import or an open, self-service Home product.

Can Alcove run locally?

The core supports local file ingestion, indexing, and search. The Home film also demonstrates an offline lookup over a selected collection. What you can search depends on the material and search mode you have configured.

Where can I learn how it works?

Start with the public documentation or the core quick start. They describe the existing software and its interfaces.
